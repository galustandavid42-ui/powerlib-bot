POWERLIB — стартовая версия Telegram-бота

Файлы:
- bot.py — код бота
- requirements.txt — зависимости

Перед запуском:
1. Установить Python 3.11+.
2. Установить зависимости: pip install -r requirements.txt
3. Задать переменную окружения BOT_TOKEN со свежим токеном от BotFather.
4. Запустить: python bot.py

Важно:
- Никогда не публикуйте токен и не отправляйте его в чаты.
- База SQLite powerlib.db создаётся автоматически.
- Это стартовая версия: видео добавляются в таблицу videos базы данных. Следующим шагом добавим удобную команду администратора для добавления роликов из Telegram.
